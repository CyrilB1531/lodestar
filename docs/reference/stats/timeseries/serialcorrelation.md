# SerialCorrelation

Whether a series carries serial dependence, and at which lags.

## Members

| Member | What it does |
| --- | --- |
| [`SerialCorrelation.Autocorrelation`](serialcorrelation-autocorrelation.md) | The autocorrelation function, with its confidence band. |
| [`SerialCorrelation.PartialAutocorrelation`](serialcorrelation-partialautocorrelation.md) | The partial autocorrelation function, with its confidence band. |
| [`SerialCorrelation.LjungBox`](serialcorrelation-ljungbox.md) | The Ljung-Box test for serial dependence, cumulated lag by lag. |
