# PointBiserial

The point-biserial correlation: how a continuous variable differs between the two sides of a
binary one.

[`Pearson`](pearson.md) with one variable coded 0 and 1, which is all `scipy.stats.pointbiserialr`
is: the coefficient is the standardised gap between the two groups' means.

| --- | --- |
