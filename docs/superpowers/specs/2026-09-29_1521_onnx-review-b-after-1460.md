# The Onnx findings of the Review B after #1401 and #1460

**Issues:** [#1521](https://github.com/CyrilB1531/lodestar/issues/1521) to
[#1528](https://github.com/CyrilB1531/lodestar/issues/1528).
**Status:** written with the work, 2026-09-29.
**Date:** 2026-09-29.

## The problem

The Review B of `Lodestar.Onnx` after #1401 and #1460, on `main` at `1cf61032`, found eight
defects:

- `Dimension` answered after `Dispose`.
- The disposal exception named the type differently per target.
- The position-table reader grew a list from a packed field without bound.
- #1423's `encoder`, `batch` and dynamic-`Embed` refusals were untested.
- Four documentation errors: a test summary claiming every batch size, XML missing the axis swap
  and ONNX Runtime's exception, an equivalence row with the wrong package's version and an
  overstated name refusal, and a csproj comment calling ONNX Runtime the repository's only
  external dependency.

## Decisions

- **`ThrowIfDisposed` goes through `Guard.NotDisposed`**, the shared guard `Lodestar.Text` and
  `Lodestar.Gpu` already use, which names the type in full on both targets.
- **A repeated field stops at 64 values**, packed or not: no transformer export this reader serves
  declares a tensor of that rank, and a file that does is answered null, as any file the reader
  cannot follow is, so the table length is then unknown rather than guessed.
