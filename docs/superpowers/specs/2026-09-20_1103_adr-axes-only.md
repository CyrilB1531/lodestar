# Keep only the ADRs that state an axis, and merge them into seven records

**Issue:** [#1103](https://github.com/CyrilB1531/lodestar/issues/1103), section 3 of
[#1071](https://github.com/CyrilB1531/lodestar/issues/1071).
**Status:** written before the work.
**Date:** 2026-09-20.

## The problem

`docs/decisions/` holds 147 records. The rule the directory exists for is that an ADR states an axis
of the project's trajectory — a parity reference, a package boundary, a target framework, a
deliberate divergence. Measured record by record, 72 of the 147 state no axis: they document a
script (`0015` the analyzer package, `0037` the pre-commit hook, `0110` the surveyor), a numerical
mechanism (`0028` Kahan's identity, `0122` the `erfc` interpolant), or a shape the code already
shows (`0040` a curve is a sealed class, `0113` a record writes its own equality).

The 75 that do state an axis state it one case at a time. Eight records answer "which library is
this stemmer frozen from", one language per record, and two of them — `0008` and `0087` — say
*Match `nltk`* in the same words. Nineteen answer "is this capability written here or delegated",
one capability per record. A reader who wants the axis reads eight or nineteen records and
assembles it.

## The decision

**Seven records, numbered `0001` to `0007`, one per family. The 147 that precede them are deleted, and the numbering restarts: a number below names a different record from the one it named before 2026-09-20.**

A merged record carries the axis as prose and a table with one row per case it absorbs, each row
naming the record it came from, so a reader tracing a decision back to `git log` still has its
number.

The 72 records that state a mechanism are deleted outright. What is still true in one moves into the
tool, the test, the guide or the `docs/equivalence.md` row that carries the mechanism, in this same
pull request, before the record goes.

## Options rejected

- **Archive under a second directory.** Rejected by the maintainer on 2026-09-19: an archive is the
  same 147 records one directory further away, and every link still has to be rewritten.
- **`Status: superseded` with a pointer.** Rejected the same day: the directory stays at 147
  records, which is the problem.
- **Keep the 75 and group them in `index.yaml` only.** Rejected on 2026-09-20: the eight stemmer
  records still state one axis eight times.
- **A merged record keeps the oldest number of the family it absorbs.** Rejected: a record that
  keeps `0008` and gains seven languages' worth of body is an edited record, which is what
  immutability forbids. A new number leaves the old body in git and nowhere else.

## Consequences

- **Immutability is narrowed, not dropped.** `tools/check_adr_immutable.py` refuses any change to an
  accepted record, deletion included. The rule becomes: **a record is never edited; a record may be
  deleted.** The guard is changed to match, and its own test pins both halves.
- **1,620 citation lines are rewritten**, in code comments, guides, reference pages,
  `docs/equivalence.md`, `CLAUDE.md`, `CONTRIBUTING.md`, `README.md` and the workflows. A citation in
  `docs/superpowers/` is pointed at the commit that still holds the record rather than at a new
  number, since [#1104](https://github.com/CyrilB1531/lodestar/issues/1104) sorts those files next.
- **`CHANGELOG.md`'s 51 citation lines are left alone.** They describe what shipped in a release
  that cited that record, and rewriting them would falsify the history the file is for.
- **`docs/decisions/index.yaml` is regenerated** by `tools/regen_adr_index.py`, and
  `docs/decisions/README.md`'s prose counts move from 147 to 7 — `tools/tests/test_adr_count_coherence.py`
  asserts the two agree.
- **The `amended_by` / `applied_by` graph disappears with the records that carried it.** Seven
  records have no edges: an amendment to one of them is a new record, as it always was.

## Definition of done

- `docs/decisions/` holds `README.md`, `index.yaml` and seven numbered records.
- No link, comment or prose line outside `CHANGELOG.md` and `docs/superpowers/` points at a deleted
  number.
- `pytest tools/tests` is green, `python3 tools/check_*.py` is green, the build is green, and
  `npx markdownlint-cli2` is clean.
