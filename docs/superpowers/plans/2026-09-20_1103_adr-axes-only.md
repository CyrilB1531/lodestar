# Seven axis records Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docs/decisions/` holds seven records, one per axis, and every citation outside `CHANGELOG.md` and `docs/superpowers/` points at one of them.

**Architecture:** Write the seven merged records first, so nothing is deleted before its replacement exists; widen the immutability guard to allow a deletion while still refusing an edit; delete the 147; rewrite the citations from one mapping table applied by a script; regenerate the index and the prose counts.

**Tech Stack:** Markdown under `docs/decisions/`, Python 3.12 under `tools/` with `pytest tools/tests`, `tools/regen_adr_index.py`, `tools/check_adr_*.py`, `npx markdownlint-cli2`.

**Spec:** [`docs/superpowers/specs/2026-09-20_1103_adr-axes-only.md`](../specs/2026-09-20_1103_adr-axes-only.md)

**Branch:** `docs/1103-adr-axes-only`

## Global Constraints

- One commit per pull request: amend as you go, never a second commit.
- Everything in English: records, comments, commit message, PR body.
- A merged record carries YAML frontmatter (`tools/check_adr_frontmatter.py` refuses one without), `**Status:** accepted · **Date:** 2026-09-20`, and empty `supersedes`/`amends`/`applies` lists — the records they would point at no longer exist.
- Comments are held to CLAUDE.md's four rules: why not what, two lines inline, eight of prose in XML documentation.
- `CHANGELOG.md` citations are never rewritten; `docs/superpowers/` citations are pointed at commit `53af23c2`, not at a new number.
- Every number a record states carries what produced it — a corpus, a named machine, or a count a guard asserts.

def test_a_deleted_record_is_allowed(tmp_repo):
    """The consolidation pass of #1103 deletes records; an edit stays refused."""
    base = tmp_repo.commit_adr("0001-axis.md", "# 0001\n\nbody\n")

- [ ] **Step 3: Allow the deletion**

```python
def deleted_now(path: str) -> bool:
    """Whether the record is gone from the working tree rather than rewritten.

    #1103 deletes every record that states no axis. What immutability protects is
    the reasoning being rewritten under a number a reader has already cited; a
    deleted record's body stays readable in git, and its number is never reused
    because .next-adr counts every ref.
    """
    return not (ROOT / path).is_file()
```

and in `main`, before the line-count finding:

```python
        if deleted_now(path):
            continue
```

- [ ] **Step 4: Run the tests again**

```bash

```

Expected: both pass.
