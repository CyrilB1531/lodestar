# DBSCAN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `Dbscan` to `Lodestar.Cluster` at `sklearn.cluster.DBSCAN` parity over a row-major span, with a precomputed-distance entry point, exact-label conformance and a benchmark against the two MIT .NET implementations.

**Architecture:** Two passes over the data — neighbourhoods, then growth from an explicit stack — behind two named static factories on one sealed class. The euclidean and precomputed paths differ only in how a row's neighbourhood is obtained, so both call one internal grower that never sees the features.

**Tech Stack:** C# on `net10.0;netstandard2.0`, xunit v3 on Microsoft.Testing.Platform, BenchmarkDotNet, scikit-learn 1.9.0 as the oracle, NumFlat 1.3.4 and `Dbscan` 3.0.0 as benchmark incumbents.

**Spec:** [`docs/superpowers/specs/2026-09-16_0759_dbscan.md`](../specs/2026-09-16_0759_dbscan.md)

**Branch:** `feat/759-dbscan`

## Global Constraints

- `net10.0;netstandard2.0`, one public API, no `#if` at a call site — `src/Shared/` carries the compatibility.
- Warnings are errors, SonarAnalyzer at `AnalysisMode=All`: no method past 7 parameters (S107), no cognitive complexity past 15 (S3776), no rectangular array (CA1814), no array-typed property (CA1819), no public static member on a generic type (CA1000).
- `eps` is inclusive: the test is `distance <= eps`, never `<`.
- `min_samples` counts the point itself.
- Noise is the label `-1`.
- Labels are compared **exactly** in the corpus — no tolerance. Distances inside the fit are compared at `1e-9` nowhere; the algorithm is discrete.
- `Lodestar.Cluster` takes no inter-package edge: it depends on nothing and nothing depends on it. This lot does not change that.
- Version: `src/Lodestar.Cluster/Version.props` 0.1.0 → 0.2.0.
- Every new public type needs a `samples/Lodestar.Sample/<Type>Sample.cs`, a page under `docs/reference/cluster/`, and a `docs/wiki-map.json` registration.

```python
def generate_cluster_dbscan() -> dict:
    """DBSCAN labels, compared exactly (#759).

    Labels are integers and the algorithm is deterministic given the neighbourhood
    order, so there is nothing here for decision 0073's numeric comparison to soften:
    a case that moves has changed answer, not drifted.

    The precomputed case is the euclidean two-feature case's own distance matrix, so
    the corpus compares the two entry points against each other as well as against the
    reference -- which is the claim the spec makes about them.
    """
    import numpy as np
    from sklearn.cluster import DBSCAN as SkDbscan
    from sklearn.metrics import pairwise_distances

    cases = []
    for fixture in _dbscan_fixtures():
        matrix = np.array(fixture["rows"], dtype=np.float64)
        model = SkDbscan(
            eps=fixture["eps"], min_samples=fixture["min_samples"], metric="euclidean").fit(matrix)
        cases.append({
            "name": fixture["name"],
            SAMPLES: [float(v) for row in fixture["rows"] for v in row],
            FEATURE_COUNT: int(matrix.shape[1]),
            "eps": fixture["eps"],
            "min_samples": fixture["min_samples"],
            "metric": "euclidean",
            "labels": [int(v) for v in model.labels_],
            "core_sample_indices": [int(v) for v in model.core_sample_indices_],
        })

    twin = next(f for f in _dbscan_fixtures() if f["name"] == "two features, two blobs and one outlier")
    matrix = np.array(twin["rows"], dtype=np.float64)
    distances = pairwise_distances(matrix)
    model = SkDbscan(eps=twin["eps"], min_samples=twin["min_samples"], metric="precomputed").fit(distances)
    cases.append({
        "name": "the same two blobs from a precomputed distance matrix",
        SAMPLES: [float(v) for row in distances for v in row],
        FEATURE_COUNT: int(distances.shape[0]),
        "eps": twin["eps"],
        "min_samples": twin["min_samples"],
        "metric": "precomputed",
        "labels": [int(v) for v in model.labels_],
        "core_sample_indices": [int(v) for v in model.core_sample_indices_],
    })

    return {
        "metadata": {
            "algorithm": "DBSCAN",
            "library": "scikit-learn",
            "library_version": version("scikit-learn"),
            "reference_calls": ['sklearn.cluster.DBSCAN(metric="euclidean")',
                                'sklearn.cluster.DBSCAN(metric="precomputed")'],
            "count": len(cases),
        },
        "cases": cases,
    }
```

```csharp
internal static class Neighbourhoods
{
    /// <summary>Every row's neighbours within <paramref name="epsilon"/>, as a flat adjacency.</summary>
    /// <remarks>
    /// Squared distances throughout: the comparison is against a squared epsilon, so no
    /// square root is taken at all. That is exact rather than merely faster — a point at
    /// exactly eps stays inside, where `Math.Sqrt` could round it out.
    /// </remarks>
    public static (int[] Offsets, int[] Indices) Euclidean(
        ReadOnlySpan<double> samples, int featureCount, int sampleCount, double epsilon)
    {
        double limit = epsilon * epsilon;
        var indices = new List<int>(sampleCount * 4);
        var offsets = new int[sampleCount + 1];
        for (int row = 0; row < sampleCount; row++)
        {
            offsets[row] = indices.Count;
            for (int other = 0; other < sampleCount; other++)
            {
                if (SquaredDistance(samples, featureCount, row, other) <= limit)
                {
                    indices.Add(other);
                }
            }
        }

        offsets[sampleCount] = indices.Count;
        return (offsets, [.. indices]);
    }

    private static double SquaredDistance(
        ReadOnlySpan<double> samples, int featureCount, int left, int right)
    {
        double total = 0.0;
        int a = left * featureCount;
        int b = right * featureCount;
        for (int feature = 0; feature < featureCount; feature++)
        {
            double gap = samples[a + feature] - samples[b + feature];
            total += gap * gap;
        }

        return total;
    }
}
```

```csharp
    /// <summary>The same adjacency, read off a square distance matrix rather than computed.</summary>
    public static (int[] Offsets, int[] Indices) Precomputed(
        ReadOnlySpan<double> distances, int sampleCount, double epsilon)
    {
        var indices = new List<int>(sampleCount * 4);
        var offsets = new int[sampleCount + 1];
        for (int row = 0; row < sampleCount; row++)
        {
            offsets[row] = indices.Count;
            int start = row * sampleCount;
            for (int other = 0; other < sampleCount; other++)
            {
                if (distances[start + other] <= epsilon)
                {
                    indices.Add(other);
                }
            }
        }

        offsets[sampleCount] = indices.Count;
        return (offsets, [.. indices]);
    }
```

- [ ] **Step 7: Write `Growth`**

```csharp
internal static class Growth
{
    /// <summary>The label a sample gets when no core point's expansion ever reaches it.</summary>
    public const int Noise = -1;

    /// <summary>Grows every cluster from the adjacency, ascending by index.</summary>
    /// <remarks>
    /// A point already labelled is never relabelled, which is what decides a border point
    /// reachable from two clusters: it joins the one grown first. The reference behaves the
    /// same way because its loop does, not because either states a rule.
    /// </remarks>
    public static (int[] Labels, int[] CoreIndices, int ClusterCount) Label(
        int[] offsets, int[] indices, int minimumSamples)
    {
        int sampleCount = offsets.Length - 1;
        var labels = new int[sampleCount];
        var cores = new List<int>();
        for (int row = 0; row < sampleCount; row++)
        {
            labels[row] = Noise;
            if (offsets[row + 1] - offsets[row] >= minimumSamples)
            {
                cores.Add(row);
            }
        }

        var core = new bool[sampleCount];
        foreach (int index in cores)
        {
            core[index] = true;
        }

        int cluster = 0;
        var stack = new Stack<int>();
        foreach (int seed in cores)
        {
            if (labels[seed] != Noise)
            {
                continue;
            }

            labels[seed] = cluster;
            stack.Push(seed);
            while (stack.Count > 0)
            {
                int current = stack.Pop();
                for (int slot = offsets[current]; slot < offsets[current + 1]; slot++)
                {
                    int neighbour = indices[slot];
                    if (labels[neighbour] != Noise)
                    {
                        continue;
                    }

                    labels[neighbour] = cluster;
                    if (core[neighbour])
                    {
                        stack.Push(neighbour);
                    }
                }
            }

            cluster++;
        }

        return (labels, [.. cores], cluster);
    }
}
```

```csharp
public static Dbscan Fit(
    ReadOnlySpan<double> samples, int featureCount, double epsilon, int minimumSamples)
{
    Guard.NotLessThan(featureCount, 1);
    Guard.NotLessThan(minimumSamples, 1);
    Positive(epsilon, nameof(epsilon));

    int sampleCount = Rows(samples, featureCount);
    (int[] offsets, int[] indices) =
        Neighbourhoods.Euclidean(samples, featureCount, sampleCount, epsilon);
    return From(featureCount, offsets, indices, minimumSamples);
}

private static void Positive(double epsilon, string paramName)
{
    // Not `<= 0` alone: a NaN fails every comparison, so it would pass a `<= 0` guard and
    // then make every neighbourhood empty, which reads as data too sparse to cluster.
    if (!(epsilon > 0.0) || double.IsInfinity(epsilon))
    {
        throw new ArgumentOutOfRangeException(
            paramName, epsilon, "Must be a positive, finite radius.");
    }
}
```

`FitPrecomputed` is the same with `Neighbourhoods.Precomputed`, after refusing a `distances` whose
length is not `sampleCount * sampleCount` with `nameof(distances)`.
