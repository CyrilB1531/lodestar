**Goal:** Ship `GlmFamily.Gamma` with the inverse and log links and the Pearson scale, at `statsmodels.GLM` 0.15.0 parity.

in `GeneralizedLinearModel.Fit` from `GlmOptions.Link`. `Families` dispatches the link functions on `GlmLink`

`Gamma` and multiplies the standard errors by its square root.

### Task 1: `GlmLink` and the link dispatch

**Files:** Create `src/Lodestar.Stats.Regression/GlmLink.cs`; modify `GlmOptions.cs`, `Internal/Families.cs`,
`Internal/Irls.cs`, `GeneralizedLinearModel.cs`, and the internal tests that call `Families`/`Irls`.

- [ ] **Step 1: The enum and the option**

```csharp
public enum GlmLink
{
    /// <summary>The family's statsmodels default: logit for binomial, log for the counts, inverse for Gamma.</summary>
    Default = 0,

    /// <summary><c>η = log μ</c>.</summary>
    Log = 1,

    /// <summary><c>η = 1/μ</c>, statsmodels' <c>InversePower</c>.</summary>
    Inverse = 2,
}
```

`GlmOptions.Link { get; init; } = GlmLink.Default;` with an `init` refusing an undeclared value.

- [ ] **Step 2: Resolution in `Fit`**

```csharp
private static GlmLink ResolveLink(GlmFamily family, GlmLink link, string optionsName) => (family, link) switch
{
    (GlmFamily.Binomial, GlmLink.Default) => GlmLink.Default,
    (GlmFamily.Poisson or GlmFamily.NegativeBinomial, GlmLink.Default or GlmLink.Log) => GlmLink.Log,
    (GlmFamily.Gamma, GlmLink.Default or GlmLink.Inverse) => GlmLink.Inverse,
    (GlmFamily.Gamma, GlmLink.Log) => GlmLink.Log,
    _ => throw new ArgumentException($"{family} does not take the {link} link here.", optionsName),
};
```

Binomial keeps `Default` as its resolved value, meaning logit.

- [ ] **Step 3: Dispatch.** `Families.InverseLink`, `LinkDerivative` and `Irls.Link` switch on the resolved link:
  `Default` → the logit arms, `Log` → `exp`/`1/μ`/`log`, `Inverse` → `1/η`, `−1/μ²`, `1/μ`. `Variance` gains
  `Gamma => mu * mu`; `UnitDeviance` gains `Gamma => 2.0 * (-Math.Log(Math.Max(y / mu, Epsilon)) + ((y - mu) / mu))`.
  The internal signatures carry one `FamilyShape` record struct `(GlmFamily Family, GlmLink Link, double Alpha)`
  in place of the separate family and alpha, which keeps `BuildWeightedSystem` at seven parameters.

- [ ] **Step 4:** the existing suite replays unchanged.

### Task 2: Scale, log-likelihood, refusals

- [ ] **Step 0: The criterion.** `Irls` divides each iteration's deviance by the Pearson scale of the previous
  mean before comparing, as `_fit_irls` does; `Irls.Scale` returns exactly 1 for the fixed-scale families.
- [ ] **Step 1: Scale.** After IRLS, for `Gamma` (the same `Irls.Scale` at the converged mean):

```csharp
double pearson = 0.0;
for (int row = 0; row < rowCount; row++)
{
    double residual = response[row] - fit.Mean[row];
    pearson += residual * residual / Families.Variance(shape, fit.Mean[row]);
}

double dispersion = pearson / residualDegreesOfFreedom;
```

  `LeastSquares.StandardErrors(fit.InverseUpper, parameterCount, dispersion)`; the other families pass 1.

- [ ] **Step 2: Log-likelihood.** `LogLikelihood.Of` takes the dispersion; the Gamma arm is
  `(1/φ)·log(y/(μφ)) − y/(μφ) − LogGamma(1/φ) − log y`, with `y/μ` clipped at epsilon.

- [ ] **Step 3: Refusals.** The response check gains `Gamma => y > 0.0 && !double.IsPositiveInfinity(y)`
  (and not NaN). IRLS throws `ArgumentException` on `design` when a Gamma mean under the inverse link is not
  above zero, naming the iteration and suggesting `GlmLink.Log`.
